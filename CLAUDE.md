## Claude Code notes

- For a new video, follow the name-first flow in AGENTS.md: ask for a name if
  missing, then create and open its content folder before collecting the brief.
- For API keys, run `pnpm setup-keys` yourself (it opens a text editor for the
  user) rather than asking for the key in chat.
- Start Studio with `pnpm dev` in the background so it keeps running while you work.
